# EventFlow — спецификации

В этом каталоге хранятся утверждённые версии продуктовой спецификации EventFlow.

## Актуальная версия

**[EventFlow — Спецификация платформы цифровых продуктов, медиамодуля и модели организаций, версия 1.2](./EventFlow_Specification_1.2.md)**

Версия 1.2 фиксирует расширение концепции EventFlow до платформы цифровых продуктов и универсальную блочную архитектуру, сохраняя ранее согласованные положения о коммерческой модели, интеллектуальных правах, медиамодуле и организациях.

## История версий

- [Версия 1.0](./EventFlow_Specification_1.0.md) — первоначальная фиксация продуктовых принципов, коммерческой модели, лицензирования, жизненного цикла приглашения и медиамодуля.
- [Версия 1.1](./EventFlow_Specification_1.1.md) — уточнение модели организаций, пользовательского доступа и жизненного цикла организации.
- [Версия 1.2](./EventFlow_Specification_1.2.md) — универсальная блочная архитектура и развитие EventFlow как платформы цифровых продуктов.

## Правила ведения

1. Каждая утверждённая версия сохраняется отдельным файлом.
2. Опубликованные версии 1.0, 1.1 и 1.2 являются историческими снимками и не перезаписываются.
3. Новые согласованные изменения оформляются новой версией документа.
4. Версия 1.x используется для уточнений и дополнений без пересмотра фундаментальных принципов; версия 2.0 — для существенного пересмотра базовой модели.
5. В спецификацию включаются согласованные решения. Предложения и открытые вопросы должны быть явно обозначены.

**Источник истины:** файлы спецификаций в этом каталоге. История изменений фиксируется средствами Git.
